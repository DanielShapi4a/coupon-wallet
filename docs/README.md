# מסמכי הפרויקט

## איך לראות את התרשימים

התרשימים כתובים בקוד `Mermaid`, והקוד הוא מקור האמת. תצוגות `Markdown` פשוטות מציגות אותו כקוד, ולא כתמונה. העברית לא קשורה לזה.

אפשר לראות את התרשימים כתמונה בשלושה מקומות:
- **`GitHub`:** מציג אותם אוטומטית.
- **`VS Code`:** עם התוסף `Markdown Preview Mermaid Support`.
- **בצ'אט:** כל תרשים חדש מוצג שם גם כתמונה.

## המסמכים

- **[vision.md](vision.md):** החזון, הבעיה, הפרסונה, ומה אנחנו לא.
- **[product-principles.md](product-principles.md):** העקרונות שלפיהם מכריעים.
- **[evidence.md](evidence.md):** ראיות מהשטח, בנפרד מהנחות.
- **[competitive-analysis.md](competitive-analysis.md):** מתחרים בישראל ובעולם, וגם רגולציה.
- **[domain-model.md](domain-model.md):** המושגים, הקשרים ביניהם וכללי המידול.
- **[prd.md](prd.md):** הדרישות לשלב 1, כולל מזהים לכל דרישה.
- **[architecture.md](architecture.md):** הרכיבים, זרימת המידע הרגיש, הזרימות המרכזיות והסקירה הספקנית.
- **[adr/ADR-001-key-management.md](adr/ADR-001-key-management.md):** ניהול מפתחות והצפנה.
- **[spikes/spike-01-key-recovery.md](spikes/spike-01-key-recovery.md):** ניסוי טכני 01, שחזור מפתחות. התוכנית, יומן ההתקדמות והתוצאות. הקוד נשאר ב־`branch` בשם `spike/key-recovery`.
- **[decision-log.md](decision-log.md):** כל ההחלטות, לפי הסדר.
